# 交付口径说明

本工程与汇报 PPT 的对应关系如下，答辩前请按此口径展示：

- **GitHub Actions**：已补齐 `.github/workflows/ci.yml`，在 Python 3.11 / 3.13 上运行 pytest 与检索评测。PPT 中“工程回归 GitHub Actions”现与仓库一致。

- **云探针（Railway `/healthz`、`/livez`）**：本地工程未包含部署配置，属于外部部署计划。展示时请明确是“部署方案”，不要表述为本地已实现。

- **品牌**：产品名“砺程 / licheng”；`上岸鸭` 与 `shangan-ya` 为仓库历史代号。三者关系以 README 顶部说明为准。

1. 删除 `__pycache__/`、`.pytest_cache/`、`.env`、`data/retrieval_memory.json`。
2. 确认 `.env.example`、`docs/design/`、`requirements-dev.txt` 均在包内。
