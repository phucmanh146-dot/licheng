# 砺程质量进阶工作台原型

打开 `index.html` 即可查看原型。

## 设计方向

“证据工作台”把材料定位、质量标准 G、差距诊断、动作卡和 Agent 建议放在同一条工作脊柱上。页面的主记忆点不是装饰，而是“证据如何走到决策”的可追溯关系。

## 原型交互

- 切换项目下拉菜单，观察多项目工作区入口。
- 点击“确认本轮标准”，观察 G 冻结和流程进入“找差距”。
- 点击材料，查看不同材料的读取/定位状态。
- 点击“开始做这一行”，观察动作卡进入进行中。
- 在 Agent 栏切换“下一动作 / 为什么 / 对话”。
- 点击“告诉我你卡在哪里…”打开求助面板；支持 `⌘ K` / `Ctrl K`。
- 点击顶部负责人视图，在负责人和复核者视图之间切换。
- 侧栏的“质量循环”是主控台；“材料与证据、行动卡、独立复核、方法迁移”是四个功能工作区。
- 切换工作区后，页面标题、面包屑和 URL hash 会同步变化；刷新页面会恢复当前工作区。

这是静态前端原型，按钮行为只用于展示交互状态，不连接真实后端。
