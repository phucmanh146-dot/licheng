# 上岸鸭 V8/V10：Agent 闭环与动态排期增量升级（2026-11-05）

## 本轮目标

在原有上岸鸭工作台、AI 中心和现有 Autoloop 代码基础上增量升级。不另建 Demo，不替换原任务数据结构，不改变原有左侧导航与主页面架构。

## 已接入的产品能力

### 1. 三个任务池进入原工作台

- 左侧原导航增加「任务池」入口，并展示待安排、缓冲箱、垃圾桶数量。
- 待安排池：进入后 24 小时内必须排布或由用户确认舍弃。
- 缓冲箱：收纳中断、突发挤占、暂缓和次要挤出任务；到期不自动滚入次日。
- 垃圾桶：只接收人工确认舍弃的任务；24 小时内可恢复，超时自动清除。
- 垃圾桶恢复后回到待安排池，不直接伪装成已排期任务。

### 2. DDL 前三天与 D-2 最后排布窗口

- D-3 15:00 扫描未排任务，计算容量缺口并按工作量 × 重要性分流。
- 任务多且重要优先安排 D-3；任务少且重要优先安排 D-3，容量不足时进入 D-2。
- 任务多且不重要安排 D-2，优先级低于高优任务。
- 任务少且不重要进入低优先级候选；用户选择保留时仍参与 D-2 排期，选择舍弃时进入垃圾桶。
- D-3 检查若错过并在 D-2 才恢复，只执行一次 D-2 最后窗口，不向过去排期、不重复弹窗。
- D-2 仍然放不下时明确暴露未安排任务，进入待安排池，要求裁剪、重排或人工舍弃，不静默推到 D-1。

### 3. 两套突发任务分支

- 番茄钟正在运行：暂停计时，保存任务进度、当前步骤、资料引用和计时现场。
- 预排时间段已被占用但番茄尚未启动：把原时间块任务移入缓冲箱，不伪造执行断点。
- 可暂缓突发：进入缓冲箱，不改动原计划。
- 即刻突发：处理完成返回后，再询问后续任务是否紧急重要；根据用户选择保留后续顺序或优先恢复被打断/挤占任务。
- 突发任务被用户声明处理完成后仍处于待证据状态，不能自动判为验收通过。

### 4. Agent 闭环工作能力

- Agent 执行请求携带当前账号的工作台状态、任务池、选中任务 ID、附件 ID 和来源链接。
- Agent 可以读取本轮明确授权的上传文件正文；对图片和视频可调用已有多模态 AI 读取实际画面/抽取帧。
- Agent 可以读取公开链接和已连接知识库内容，并保存每次工具执行的检查点。
- 附件读取按本轮上传 ID 授权，不允许模型任意枚举或读取其他文件。
- 跨会话恢复继续使用原 Agent task、Autoloop 检查点和材料版本；没有找到历史现场时如实说明。
- 工具执行失败必须记录错误和下一步，不得把计划、尝试或口头汇报写成成果。
- Agent 不直接覆盖每日计划检查点；排期仍由工作台规则引擎执行。

## 回归验证

本轮已执行：
- Autoloop 规则 JavaScript 语法检查。

- Autoloop 排期解析与 15:00 规则测试：通过，覆盖 DDL 三天内任务保护和远期非紧急任务顺延。
