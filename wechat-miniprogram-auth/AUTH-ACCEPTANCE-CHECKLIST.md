# 上岸鸭 V10 手机号账号闭环验收清单

## A. 新用户注册
1. 未注册手机号请求验证码，服务端真实返回短信服务商 SendStatusSet.Code=Ok。
2. 60 秒内重复请求，服务端拒绝。
3. 输入错误验证码，校验失败且错误次数递增；第 6 次错误前后均不可绕过。
4. 等待 5 分钟后使用验证码，必须提示过期。
5. 正确验证码只产生 10 分钟一次性验证 challenge，不直接创建账号。
6. 输入不符合规则的密码（不足 8 位、无字母、无数字），拒绝创建。
7. 两次密码不一致，前端阻止提交。
8. 正确密码创建账号，服务端存储 scrypt 哈希而非明文；返回 bearer token。
9. 同一手机号再次注册，拒绝创建第二个账号。
10. 新账号登录后 /me 返回正确 phone 和 user id。

## B. 登录与密码安全
1. 正确手机号+密码登录成功。
2. 错误密码返回 401，不签发 token。
3. 未注册手机号登录失败。
4. token 过期或登出后，/me 返回 401。
5. 忘记密码流程必须先短信验证，再重设密码。
6. 重设密码后，旧 session 全部失效；使用新密码可重新登录。

## C. 旧账号迁移
1. 使用原用户名/密码登录，获得原 users.id 对应的 bearer session。
2. 使用未绑定手机号接收短信并验证。
3. 提交 bind-phone 后更新原 users.phone 和 password，不创建新 users 行。
4. 验证 users.id 与 storage 保持不变，原任务/资料仍归属该账号。
5. 已绑定其他账号的手机号不得再次绑定。

## D. 账号隔离
1. 手机号 A 和手机号 B 注册后，users.id 和 storage 必须不同。
2. A 创建的任务、资料、执行记录不能由 B 的 token 读取。
3. B 的 token 不得访问 A 的私有资源；服务端必须按 user id/storage 过滤，而不是只依赖前端隐藏。
4. 退出 A 后，A 的 token 不能再访问私有 API。

## E. 微信真机和正式发布
- 在微信开发者工具使用真实 AppID 编译；touristappid 仅用于本地预览，不可发布。
- API_BASE 必须指向实际已部署且含本分支后端代码的 HTTPS 域名。
- request 合法域名已在公众平台配置。
- 腾讯云短信应用、签名和模板已审核通过；Railway Variables 已配置全部密钥。
- 真机完成 A–D 全部测试，并保留短信发送状态、接口响应、账号数据隔离检查记录。
