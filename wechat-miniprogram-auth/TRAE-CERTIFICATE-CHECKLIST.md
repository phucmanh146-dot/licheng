# TRAE 训练营第一期结营作业验收清单

来源：TRAE 官方中文社区主题 https://forum.trae.cn/t/topic/463231
主题标题：【回放资料+结营作业安排】TRAE 训练营第一期

## 官方作业要求（逐项核对）

### 第一节课作业
- [ ] 提交作品 Demo 体验链接或文件
- [ ] 提交第一个真实用户反馈截图

### 第二节课作业
- 官方帖子未列出单独作业（标记为无），不自行编造交付物

### 第三节课结营作业
满足下列至少一种可交付状态：
- [ ] 成功发起小程序审核；或
- [ ] 小程序已经上线；或
- [ ] 若上线审核未通过，提交可扫码体验的小程序真机测试二维码

## 结营帖必须包含

标题格式：
`【第一期结营作业】欢迎体验我的小程序：上岸鸭`

1. **小程序介绍**
   - 小程序名称：上岸鸭
   - 面向对象：需要管理多条学习/项目主线、容易因任务卡住而影响整体进度的个人用户
   - 一句话介绍：根据截止日期、固定事务、精力与真实执行证据，帮助用户把计划变成可核验的完成结果。

2. **小程序界面截图 / 动图演示**
   - 至少 3 张
   - 展示主要页面和核心功能；建议选注册登录、DDL/任务排期、成果证据验收三个主流程
   - 截图必须来自真实微信小程序运行，不用网页截图冒充

3. **TRAE 开发截图**
   - 3 张完整界面截图
   - 展示 TRAE 开发过程，不只是最终代码；截图需能看清项目和对话/编辑过程

4. **关键开发步骤 Session ID**
   - 至少 3 个
   - 选择需求分析、核心页面实现、接口/调试修复三个关键步骤的真实 TRAE Session ID
   - 不得伪造或用 ChatGPT 对话 ID 替代

5. **体验二维码**
   - 提供可直接扫码体验的小程序二维码
   - 审核未通过时可使用微信开发者工具上传的体验版二维码，但必须是真机可扫码的微信小程序码

6. **微信后台版本截图**
   - 小程序后台“版本管理”截图
   - 证明作品在训练营期间开发/上传

7. **审核或发布时间截图**
   - 清晰显示审核发起、审核状态或发布时间
   - 官方帖子明确要求截图日期至少为 2026-10-27 当天或之后

## 结营通过判断

- **达到最低结营作业交付条件**：第一节课 Demo + 首位真实用户反馈；第三节课至少有审核发起、已上线、或真机测试二维码之一；结营帖的 1–7 项证据完整。
- **稳妥提交建议**：即使审核未通过，也先完成体验版上传并提供真机二维码，同时保留审核状态/版本管理截图；补齐三张 TRAE 开发截图和三个 Session ID。
- **不得误判**：GitHub 有代码、网页能打开、开发者工具模拟器能运行，均不能单独证明“已上线”或“已完成结营作业”。

## 当前阻塞
1. Desktop Commander 设备离线，当前无法在用户电脑运行微信开发者工具或从 TRAE 本机历史中提取 Session ID。
2. 用户尚未提供正式小程序 AppID；不能用 touristappid 作为正式提交。
3. Railway 短信服务配置缺失；必须先配置真实可用的短信服务。
4. 备案主体资料和管理员人脸核验必须由真实主体/负责人本人在微信公众平台完成，不能代填虚假身份信息。
